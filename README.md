# College labs

Smaller lab exercises from my BEng (Hons) Software & Electronic Engineering course at ATU Galway, collected in one place. Each folder is a copy of the current files from what used to be a separate repository.

| Folder | What it is | Tech |
|---|---|---|
| [`LennonLeaf/`](LennonLeaf) | MySQL schema for a bookshop: authors, books, customers, orders and order items, with foreign keys and CHECK constraints. | SQL, MySQL |
| [`Week-8/`](Week-8) | Maven + JUnit 5 lab: a Calculator class with error handling and 7 unit tests. | Java, Maven, JUnit 5 |
| [`Week-9/`](Week-9) | Maven + JUnit 5 lab: a Passenger class with input validation, 4 unit tests and the JaCoCo coverage plugin. | Java, Maven, JUnit 5, JaCoCo |
| [`Sem-2---Week-3---Database-Normalization/`](Sem-2---Week-3---Database-Normalization) | SQL lab: a normalised student information schema (Student, Course, Enrollment). | SQL, MySQL |

To run a Maven lab: `cd Week-8` (or `Week-9`) and run `mvn test`.
